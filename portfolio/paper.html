Predicting Content Refresh Opportunities Using Search Performance Signals

Abstract

This capstone project explores whether historical search performance signals can be used to identify content refresh opportunities. A machine learning workflow was applied to analyze anonymized content performance data and generate ranked recommendations. The objective was to support content prioritization decisions while maintaining transparent and responsible model evaluation practices.

1. Research Question

Can historical search performance features help identify content refresh opportunities and support content prioritization decisions?

2. Data

  • Anonymized content performance dataset
  • Search-related performance metrics
  • Historical trend indicators
  • Content-level observations

Private information, direct URLs, and client-identifying information were excluded.

3. Methodology

  • Data cleaning and preprocessing
  • Feature engineering
  • Exploratory Data Analysis
  • Baseline model development
  • Validation and leakage auditing
  • Recommendation generation

The model was evaluated using both baseline and honest validation approaches.

4. Results (vs Baseline)

Metric Baseline Split Honest Split
Accuracy 0.84 0.78
F1 Score 0.81 0.74

The honest validation split produced lower performance than the baseline split, suggesting that the baseline estimate was optimistic. The honest split likely provides a more realistic estimate of future deployment performance.

5. Limitations

  • Results are based on historical observations.
  • Performance may vary under future conditions.
  • The model identifies patterns, not causal relationships.
  • Recommendations require human review.

6. Ranked Recommendations

  1. Prioritize high-scoring refresh opportunities.
  2. Review declining content with strong historical performance.
  3. Monitor content showing unstable performance patterns.
  4. Require human review before implementation.

Final Statement

This project demonstrates a complete machine learning workflow from research question definition through recommendation generation. All findings are observational and directional. Recommendations should be used as decision-support guidance and require human review before implementation.
