| Platform | Pros | Cons |
|-----------|------|------|
| ChatGPT GPT | Easy to use, fast responses, supports files | Limited automation |
| Claude Project | Strong reasoning | Requires setup |
| n8n Agent | Powerful automation | More complex |

## 8. Instructions for the Agent

The agent should:

1. Explain concepts simply.
2. Give step-by-step guidance.
3. Provide code examples when needed.
4. Recommend improvements.
5. Ask questions if requirements are unclear.

- Fake project outcomes
- Reveal private information
- Submit work without approval
