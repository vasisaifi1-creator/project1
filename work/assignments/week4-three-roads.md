# Three Roads: Choose Your Stack with AI

## 1. My Constraints

### Budget
- Free tools only.

### Honest Skill Level
- Beginner to Intermediate in HTML, CSS, JavaScript, Git, GitHub, and AI tools.

### What My Portfolio Needs
- Home page
- About Me
- Skills
- Projects
- AI Projects
- Resume
- Certificates
- GitHub Profile
- Contact Page

### How My Work Must Be Displayed
- Project screenshots
- GitHub repository links
- Live portfolio website
- Resume PDF
- Certificates
- Clean and responsive design

### Backend
- Not required yet. A static website is enough for my current portfolio.

---

# 2. Three Stack Options

## Option 1 – HTML + CSS + JavaScript (Simplest)

### Build With
- HTML
- CSS
- JavaScript

### Hosting
- GitHub Pages

### Backend
- No

### Advantages
- Completely free
- Easy to learn
- Fast to build
- Easy to maintain
- Perfect for beginners

### Trade-offs
- Static website
- No login system
- No database

---

## Option 2 – React + Vite

### Build With
- React
- Vite

### Hosting
- Netlify or Vercel

### Backend
- Not required initially

### Advantages
- Modern user interface
- Reusable components
- Easier to scale later

### Trade-offs
- More setup
- Requires React knowledge
- Slightly harder than plain HTML/CSS/JS

---

## Option 3 – Next.js + Firebase (Most Powerful)

### Build With
- Next.js
- Firebase

### Hosting
- Vercel

### Backend
- Firebase Database

### Advantages
- Authentication
- Database support
- Dynamic content
- Highly scalable

### Trade-offs
- Highest learning curve
- More maintenance
- More complex project structure

---

# 3. Pressure Test

### What breaks if I choose the simplest stack?
I cannot add user accounts, databases, or advanced dynamic features without changing the technology later.

### What do I maintain if I choose the most powerful stack?
I would need to maintain Firebase, authentication, deployment, and additional project configuration.

### Can I finish it in two weeks?
Yes. Using HTML, CSS, and JavaScript, I can complete the portfolio within two weeks.

### Does it show my work properly?
Yes. It can clearly display my projects, AI assignments, GitHub repositories, certificates, resume, and contact information.

---

# 4. Final Decision

I choose **HTML, CSS, and JavaScript hosted on GitHub Pages**.

This stack matches my current skills and allows me to build a clean, responsive, and professional portfolio using only free tools. It is easy to maintain and lets me showcase my AI projects, GitHub repositories, resume, certificates, and skills effectively.

I considered React + Vite because it offers a modern development experience, but it requires additional learning and setup.

I also considered Next.js + Firebase because it is powerful and scalable, but it is more complex than I need for my current portfolio.

For now, HTML, CSS, and JavaScript provide the best balance between simplicity, maintainability, and completing the project on time. As my skills improve, I can upgrade the portfolio to React or Next.js in the future.

---

# Conclusion

After comparing three different technology stacks, I selected HTML, CSS, and JavaScript because they meet my current needs, are completely free, easy to maintain, and display my work effectively. This choice allows me to build a professional portfolio now while keeping the option to expand it later.
